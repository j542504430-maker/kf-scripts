第二部分 具体问题怎么解决

A. Claude Code / 客户端

A1 提示"自动更新失败（claude.exe 正在被占用）"

怎么做：不是权限问题，是进程还开着、文件被锁。

  • 让客户关掉所有 Claude Code 窗口（包括编辑器里挂着的）
  • 新开终端窗口
  • 执行 claude update
  • 更新完重新打开

    • 原话（11-26）：

    您好，看您截图最下面提示自动更新失败（claude.exe 正在被占用），麻烦您先把电脑上所有开着的 Claude Code 窗口（包括编辑器里挂着的）全部关掉，然后新开一个终端窗口输入 claude update 更新到最新版本，更新完再重新打开试试

    另一种情形（11-16）：软件自动更新但没外网导致闪退。

    原话：大概率是软件可能启动了自动更新，又没有外网所以闪退了。您可以卸载后以全局模式再重装一下软件

    A2 界面不是中文

    怎么做：中文界面依赖登录态/网络，需要开 VPN 后重启客户端。

    原话：需要开启 vpn，重启就会加载中文界面

    补充：客户不想折腾时说——使用其实没有区别，让他用中文回复就可以

    A3 出现 Auto Mode 计费提示，客户不敢继续

    怎么做：这是 Claude Code 对官方接口的计费提示，走第三方 API 不受影响，直接回车。

    原话（11-26）：您好，这是 Claude Code 官方新版 Auto Mode 的计费兼容提示，主要针对官方接口的 classifier 计费机制。第三方 API 接入不需要这个功能，不影响正常使用，直接回车继续即可

    A4 报错说被"安全分类器"拦了

    怎么做：这是 Anthropic 官方加在客户端的实时分类器，会误拦正常对话，不等于客户违规。给官方出处安抚，让客户重发。

    原话（11-24）：您好，这个是 Anthropic 官方在 Claude Code 上加的实时安全分类器拦的。官方自己也写了：能力更强所以 safeguards 更严，有时会误拦正常、非安全类对话；拦到也不等于你违规。

    报错原文会链到 Usage Policy：https://www.anthropic.com/legal/aup（写明：碰到拦截本身≠违反 AUP）

    官方文档 Safeguard refusals：https://platform.claude.com/docs/en/build-with-claude/safeguard-refusals

    A5 MCP / 插件装了没生效（Connectors 与 Claude Code 混淆）

    怎么做：两套配置互不相通，按客户实际使用位置分开处理。

    客户在哪用怎么配
    Claude Desktop 普通对话Customize → Connectors 里打开扩展（如 blender），并确保软件侧插件服务已启动
    Claude Code（终端/编辑器）单独配 MCP：claude mcp add blender -s user -- uvx blender-mcp，或项目根目录建 .mcp.json

    原话（11-25）：您在 Customize -> Connectors 里装的 blender 只是 Claude Desktop 桌面端普通对话用的本地扩展，而截图里提示没找到配置的是 Claude Code。这两边的 MCP 配置是分开的，不会自动互通

    补充（11-25）：把您需要连接的 mcp 链接发给 codex 让他帮您连就可以

    A6 客户端"后端报错"、连不上

    怎么做：先排除客户端本身，再判断网络还是服务端；仍不行就远程。

    原话：您好，看了下应该是您客户端的后端报错
